# Dispatched Worker Policy

The controller owns orchestration. Skip orchestration and product-layer skills (`development-process`, `product-process`, `brainstorming`, planning/execution, product discovery/brief, architecture assessment/extraction, and readiness gates).

Still invoke every prompt-required skill and any task-signalled craft or verification skill: `test-driven-development` for implementation, `systematic-debugging` for a bug or unexpected failure, UI craft for UI work, and `verification-before-completion` before reporting done. A `BLOCKED` condition must never be skipped or ignored; report it to the controller.
