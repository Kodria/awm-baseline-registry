# Compact Slices v2

V2 is a separate compact schema. It retains every v1 manifest and five-section
prose requirement, adding exactly one field: each slice has one
`implementerProfile` of `mechanical`, `integration`, or `judgment`. Never put a
model, vendor, selection, policy digest, or capability receipt in a plan.

Use v2 only when the plan explicitly declares `**Modo de despacho:** awm-routed`,
the installed CLI contract reports support, and approved policy is ready. If any
routing prerequisite is absent, block instead of changing the selected mode. The CLI,
not this registry, validates, resolves, admits, reserves, observes, and gates.

Mechanical owns closed local behavior; integration owns known interfaces;
judgment owns public, cross-cutting policy, custody, security, admission, and
root recovery. Missing decisions return planning-required.
